MythicSMP - Sito Web
======================

COME APRIRLO SUL TUO PC:
1. Scompatta questo ZIP dove vuoi (es. Desktop)
2. Apri il file index.html con il browser (doppio click)
3. Fatto! Non serve installare niente.

COME CARICARLO ONLINE (es. hosting / GitHub Pages / Netlify / ecc):
- Carica TUTTA la cartella così com'è: index.html + cartella assets/
- La pagina principale deve rimanere index.html
- Non rinominare assets/logo.png, altrimenti l'hero non si vede

COME CAMBIARE L'IP QUANDO ESCE:
1. Apri index.html con Blocco Note / VS Code
2. Cerca (Ctrl+F) "IP IN ARRIVO" e sostituiscilo con il tuo IP reale, es. play.mythicsmp.it
   Ci sono 3 punti: hero, sezione Come Giocare, footer.
3. Salva e ricarica la pagina.
   Suggerimento: quando hai l'IP reale dimmelo e te lo aggiorno io in tutto il sito.

COME CAMBIARE DISCORD / SOCIAL:
- Cerca "discord.gg/mythicsmp" in index.html e sostituiscilo col tuo invito.
- TikTok e YouTube sono nel footer.

STRUTTURA:
- index.html = tutto il sito
- assets/logo.png = il tuo logo natalizio (hero + navbar + footer)
